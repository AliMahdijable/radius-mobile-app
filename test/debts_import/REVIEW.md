# مراجعة المال — «استيراد / تصدير الديون» بالتطبيق (٢٣ نوفمبر ٢٠٢٦)

عميلٌ جديد لمسارٍ قائمٍ مُراجَع: `POST /api/v2/debts/bulk-import` (server.js، الخادم لم يُمسّ) و`POST /api/v2/deleted-debts/import`.
ما يقرّره العميل: **أيّ مشتركٍ يُكتب عليه أيّ مبلغ** (المطابقة) و**كيف تُرسل الدفعات وتُقرأ نتائجها**.

| البند | الحكم | الدليل |
|---|---|---|
| M1 مصدر المبلغ | PASS | المبلغ من ملفّ الوكيل نفسه، بقراءة الموقع حرفاً (`parseAmountCell`: أرقام عربيّة/فارسيّة، فواصل، أوّل رقم، القيمة المطلقة)؛ غير المقروء ⇒ «غير صالح» لا صفر يُطبَّق. 88 حالة = الموقع. |
| M2 الهويّة والنطاق | PASS | الفاعل من التوكن بالخادم؛ الموظّف 403 OWNER_ONLY والقسم لا يُعرض له (`!Perms.isEmployee`)؛ «كل الشركات» ⇒ `MergedSection.openOnly` (لا توجيه). |
| M2b المطابقة | PASS | `matchDebtRows` منقولةٌ حرفاً من `lib/debts-match.ts` + تطبيع `lib/debts-pdf.ts` (NFKC من Node + تركيب الهمزة/المدّة): `debts_import_parity_test` يقارنها بكود الموقع المترجَم نفسه — 1,809 صفّاً في 160 حالة (كلّ الأنواع الستّة)، 889 نصّاً، 164 هاتفاً، 59 عنواناً، 12 CSV، 8 جداول، وExcel كتبه SheetJS — مطابقٌ كلّه. |
| M3 مرّةً واحدة | PASS | زرّ التطبيق يُعطَّل أثناء الدفعات والقسم لا يُغلق (`PopScope`)؛ الخادم: نافذة ٣٠ دقيقة لكلّ صفّ + عمليّة واحدة لكلّ مشترك. |
| M4 ثلاث نتائج | PASS (أشدّ من الموقع) | دفعةٌ بلا ردّ (مهلة/شبكة/5xx) ⇒ صفوفها «غير مؤكَّدة» بأسمائها، **لا تُعاد** ولا يُرسل ما بعدها (`لم يُرسل N`)؛ رفضٌ 4xx ⇒ «توقّف» برسالته. اختبار: الدفعة ٢ تنقطع ⇒ لا ثالثة. |
| S3 الرسائل | PASS | أسباب الخادم لكلّ صفٍّ لم يُطبَّق تُعرض كما هي. |
| U1 العقد | PASS | الجسم نفسه الذي يرسله الموقع (`rows:[{username, amount}]`, `mode`)، دفعات ١٥. |
| U2 المزوّدون | PASS | ساس، ايرث لنك، فايبر اكس، المُضافة بالمسار نفسه؛ FTTH مخفيّ كالموقع (`noFtth`). |
| T | PASS | `debts_import_parity_test` (9) + `debts_import_screen_test` (11: التصدير، الاستيراد، الدفعات ١٥/١٥/٢، غير المؤكَّد، ديون المحذوفين وconfirmRepeat، PDF/xls، الكبير، 320–480 × 1.2، الموظّف/FTTH). لا مال حقيقيّ: خادمٌ وهميّ. |

**ما يختلف عن الموقع عمداً:** PDF وxls/ods لا تُقرأ بالتطبيق بعد (رسالةٌ واضحة: «ارفعه من الموقع» / «احفظه xlsx أو CSV»)؛ النتيجة فوق المعاينة (على الهاتف كانت تُدفن تحت الصفوف)؛ «غير مؤكَّد» بدل خطأٍ عامّ.

**إعادة توليد حالات المقارنة:** `test/debts_import/gen/` — `WEB=<client-v2> node test/debts_import/gen/build.cjs && WEB=<client-v2> OUT=test/debts_import/parity_cases.json node test/debts_import/gen/gen.cjs`.
